# Old files you can delete from the GitHub repo

These are left over from the first versions of the app (before September 2026). The app no longer loads them;
their content now lives in `tools/legacy_data/` and is used from there. Uploading a zip through the GitHub
website never deletes files, so they have to be removed once by hand (on GitHub: open the file or folder →
"…" → Delete).

- `data/` (the whole folder)
- `src/` (the whole folder)
- `dataLoader.js`
- `flashcardGenerator.js`
- `styles.css`
- `content_manifest.json`
- `github/` (without the dot – the real one is `.github/`)
- `PATCH_NOTES.txt`, `PATCH_NOTES_V30_FIX.txt`, `VERIFICATION_REPORT.txt`
- `dist/` (an old APK)

You can delete this file afterwards too.
